# ZGCLab 境外机构数据平台

ZGCLab 是一个纯静态、可离线运行的数据检索与展示系统。它把需求 1 的已审核交付快照按“机构 × 采集角度”组织起来，适合核验数据覆盖、检索证据、查看原文依据和导出筛选结果。

## 当前数据范围

| 采集角度 | 目标表 | 字段数 | 记录数 |
| --- | --- | ---: | ---: |
| 新闻舆情 | `t_kt_public_sentiment` | 16 | 3,675 |
| 机构官网 / 线索 | `t_kt_risk_clue_detect` | 35 | 1,468 |
| 社交媒体 | `t_kt_social_media_content` | 34 | 1,846 |

当前快照共 **6,989 条**已审核入表记录，覆盖 **20 个验证机构**。数据来源为 `20261011-current-reviewed` 交付包。

## 页面与功能

- **数据总览**：机构覆盖率、总量 KPI、三个角度分布、机构数据量排行、月度趋势、平台 / 风险 / 标签统计、最新入库记录。
- **机构库**：按中文名、英文名、ktid、机构类型检索；按数据量、名称或 ktid 排序；导出机构清单 CSV。
- **机构详情**：查看单个机构的三类数据，支持角度切换、全文字段检索、分页和当前角度 CSV 导出。
- **数据浏览**：支持全部数据跨角度检索，也可以只看新闻舆情、官网线索或社交媒体；可组合机构、关键词、主题标签 / 风险等级 / 平台、日期范围和排序条件。
- **结果操作**：当前筛选结果导出 CSV、复制查询链接、点击行打开详情、单条记录导出 CSV。
- **记录详情**：展示快照中的全部字段、长文本、风险与标签；原文地址使用安全协议校验；可打开原文、查看机构或复制记录深链接。
- **任务与交付**：说明数据链路、三张目标表、20 个验证单位和交付口径。

## 在线查看

仓库开启 GitHub Pages 后，直接打开仓库对应的 Pages 地址即可。该站点没有后端请求，页面和 `data/` 下的快照一起发布，支持断网查看；首次进入某个角度时才加载对应的大型数据文件。

## 本地或服务器运行

```bash
cd /home/ubuntu/zgclab-1-web
python3 -m http.server 8787 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8787/`。服务器上使用 tmux 常驻：

```bash
tmux new -A -s zgclab-1-web
cd /home/ubuntu/zgclab-1-web
python3 -m http.server 8787 --bind 127.0.0.1
```

Mac 端通过 SSH 转发：

```bash
ssh -L 8787:127.0.0.1:8787 social
```

然后打开 <http://127.0.0.1:8787/>。

## 更新快照

`data/meta.js`、`data/news.js`、`data/clue.js` 和 `data/social.js` 由 `build_data.py` 生成。默认读取需求 1 的交付包：

```bash
cd /home/ubuntu/zgclab-1-web
python3 build_data.py
```

也可以显式指定交付包目录：

```bash
python3 build_data.py /path/to/delivery-package
```

生成脚本会：

- 按三张目标表生成可供前端直接加载的 JavaScript 快照；
- 为记录生成快照内稳定 ID，方便详情深链接和导出；
- 截断正文、摘要和翻译字段，控制静态站点体积；
- 生成总量、机构计数、时间趋势、标签、风险和平台统计；
- 在公开元数据中只写交付包名称，不写服务器绝对路径。

更新后重新加载静态服务即可。提交前建议检查：

```bash
node --check app.js
python3 -m py_compile build_data.py
git diff --check
```

## 交付口径

- 数据来自需求 1 已审核入表的交付快照，不是前端编造的样例。
- 当前页面只覆盖交付包内的 20 个验证单位，不代表历史全量数据。
- 主键、创建 / 修改时间、删除标记等系统字段按接收系统约定处理；本地快照使用稳定 ID 支持页面定位。
- 无法确认的采集字段保持空值，不用“未知”“无”等词替代。
- CSV 导出在浏览器本地生成，导出的内容只来自当前已加载的静态快照。
